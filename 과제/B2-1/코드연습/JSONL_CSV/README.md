# JSONL/CSV 코드작성 연습

목표: 예시를 안 보고도 JSONL과 CSV를 한 줄씩 읽고 쓰는 코드를 쓸 수 있게 되기 (전체 약 1시간)

## 사용법
```bash
cd 과제/B2-1/코드연습/JSONL_CSV            # 저장소 맨 위에서 한 번만
python3 문제/1_1_영화를_한줄로_바꾸기.py      # 직접 실행
python3 채점.py 1                           # 1단계 전체
python3 채점.py 1_1                         # 한 문제
python3 채점.py 종합                        # 종합 테스트
```

## 단계마다 반복
1. 개념 파일을 읽고, 예시를 복사하지 말고 직접 친다.
2. 문제를 풀고 채점한다. 막히면 개념을 보고, 다시 닫고 쓴다.
3. 통과하면 함수 안을 지우고 **안 보고 한 번 더** 쓴다.
4. "말로 설명하기"에 답한다. 모르면 "모름"이라고 한다.
