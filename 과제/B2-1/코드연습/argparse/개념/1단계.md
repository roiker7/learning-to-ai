# 1단계: 아는 문법에서 출발하기

## 1. 메서드는 이미 써 봤다
```python
names = []              # 리스트를 만들고
names.append("민수")    # 그 리스트에게 "추가해"라고 시킨다
```
`names`처럼 데이터와 기능을 함께 가진 것을 **객체**, `.append()`처럼 객체에게 시키는 함수를 **메서드**라고 한다.
모양은 항상 `객체.메서드(재료)`이다. argparse도 똑같은 모양을 쓴다.

## 2. import
`import sys`는 파이썬에 들어 있는 `sys` 도구를 가져온다. 안의 것은 `sys.이름`으로 꺼낸다.

## 3. sys.argv
터미널에 친 내용이 **문자열 리스트**로 들어온다.
```python
import sys
print(sys.argv)
```
`python3 show.py 사과 3`으로 실행하면 `['show.py', '사과', '3']`이다.
- `[0]`은 파일 이름, 내가 친 값은 `[1]`부터
- `3`도 문자열 `'3'`
- `sys.argv[1:]`은 1번부터 끝까지 (슬라이싱)

