# 1단계: yield와 next

**제너레이터**는 값을 한꺼번에 만들지 않고, 달라고 할 때마다 하나씩 만들어 건네주는 것이다. 함수 안에 `yield`가 있으면 그 함수는 제너레이터를 만드는 함수가 된다.

```python
def greet():
    print("시작")
    yield "안녕"
    print("다시 시작")
    yield "잘 가"
    print("끝")

g = greet()
print("아직 아무것도 실행되지 않음")
print(next(g))
print(next(g))
```
결과
```
아직 아무것도 실행되지 않음
시작
안녕
다시 시작
잘 가
```

| 코드 | 일어나는 일 |
|---|---|
| `g = greet()` | 제너레이터만 만든다. 함수 안은 **아직 실행되지 않는다** |
| 첫 `next(g)` | `yield "안녕"`까지 실행하고, 값을 건네고 **멈춘다** |
| 다음 `next(g)` | 멈춘 곳 **다음 줄부터** 이어서 `yield "잘 가"`에서 멈춘다 |

한 번 더 `next(g)`를 하면 "끝"을 출력하고, 줄 값이 없어서 `StopIteration` 오류가 난다. `for`는 이 신호를 알아서 처리하므로 오류 없이 끝난다. 보통은 `for`를 쓴다.

```python
for word in greet():
    print(word)
```

## return과 yield
| | `return` | `yield` |
|---|---|---|
| 값을 준 뒤 | 함수가 끝난다 | 멈췄다가 이어서 실행한다 |
| 줄 수 있는 값 | 한 번 | 여러 번 |

제너레이터는 **한 번만** 쓸 수 있다. 다 꺼낸 뒤 다시 `for`를 돌리면 아무것도 나오지 않는다. 다시 쓰려면 `greet()`를 새로 부른다.

반복문 안에서도 쓸 수 있다.
```python
def stars(n):
    for i in range(1, n + 1):
        yield "*" * i

print(list(stars(3)))   # ['*', '**', '***']
```
`list(...)`는 값을 전부 꺼내 리스트로 만든다. 결과를 확인할 때만 쓴다. 전부 메모리에 올라가기 때문이다.
