# 2단계: 필요한 만큼만 꺼내기

리스트는 값을 **모두 만들어 메모리에 둔다.** 제너레이터는 **지금 필요한 값 하나**만 만든다.

```python
def make_list(n):
    result = []
    for i in range(n):
        print("만듦", i)
        result.append(i)
    return result

def make_gen(n):
    for i in range(n):
        print("만듦", i)
        yield i

for x in make_list(3):
    print("사용", x)
    break
print("---")
for x in make_gen(3):
    print("사용", x)
    break
```
결과
```
만듦 0
만듦 1
만듦 2
사용 0
---
만듦 0
사용 0
```
둘 다 하나만 썼지만 리스트는 셋을 다 만들었다. 100만 개라면 차이가 크다.

끝이 없는 값도 다룰 수 있다.
```python
def numbers():
    n = 1
    while True:
        yield n
        n += 1

for x in numbers():
    if x > 3:
        break
    print(x)          # 1, 2, 3
```

조건에 맞는 것만 내보내려면 `if` 안에서 `yield`한다.
```python
def short_words(words):
    for word in words:
        if len(word) <= 2:
            yield word
```

제너레이터 안에서 `return`을 쓰면 **더 내보내지 않고 끝낸다.**
```python
def until_stop(words):
    for word in words:
        if word == "그만":
            return
        yield word
```
