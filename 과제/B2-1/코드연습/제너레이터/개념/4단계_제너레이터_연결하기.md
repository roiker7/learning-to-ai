# 4단계: 제너레이터 연결하기

제너레이터를 다른 제너레이터에 넣을 수 있다. 각 함수는 한 가지 일만 한다.

```python
def numbers(n):
    for i in range(1, n + 1):
        print("꺼냄", i)
        yield i

def double(items):
    for item in items:
        print("두 배", item)
        yield item * 2

for x in double(numbers(2)):
    print("결과", x)
```
결과
```
꺼냄 1
두 배 1
결과 2
꺼냄 2
두 배 2
결과 4
```
`numbers`가 다 끝난 뒤 `double`이 시작하는 것이 **아니다.** 값 하나가 끝까지 지나간 뒤 다음 값을 꺼낸다. 그래서 중간에 전체 목록이 쌓이지 않는다.

## 연습문제
### 4-1 (`문제/4_1_두_단계_연결하기.py`)
`long_words(words, n)`은 길이가 n 이상인 단어만, `add_mark(words)`는 단어 뒤에 `!`를 붙여 내보낸다. 둘을 연결하면 긴 단어에만 `!`가 붙는다.

## 종합 테스트 (`문제/종합_기온_파일_처리.py`)
개념 파일을 닫고 푼다. 한 줄에 기온이 하나씩 적힌 파일을 처리한다.
- `read_temps(path)`: 기온을 `float`(소수)으로 바꿔 하나씩 내보낸다. 빈 줄은 건너뛴다. `float("31.5")`는 `31.5`
- `hot_days(temps, limit)`: `limit` 이상인 기온만 내보낸다.
- `first_n(temps, n)`: 앞에서 n개만 내보내고 끝낸다.

세 함수를 연결하면 "30도 이상인 날 중 앞의 2개"를 구할 수 있다.
