# 3단계: 파일을 한 줄씩 읽기

파일은 `for`로 돌리면 한 줄씩 나온다. 파일 전체를 메모리에 올리지 않는다.

```python
def read_lines(path):
    with open(path, encoding="utf-8") as file:
        for line in file:
            yield line.rstrip("\n")

for line in read_lines("예시자료/메모.txt"):
    print(line)
```

| 코드 | 뜻 |
|---|---|
| `with open(...) as file` | 다 쓰면 파일을 자동으로 닫는다 |
| `encoding="utf-8"` | 한글이 깨지지 않게 글자 저장 방식을 정한다 |
| `for line in file` | 한 줄씩 꺼낸다 |
| `rstrip("\n")` | 줄 끝의 줄바꿈을 없앤다 |
| `line.strip()` | 앞뒤 공백과 줄바꿈을 모두 없앤다. 빈 줄이면 `""`이 된다 |

`file.read()`와 `file.readlines()`는 **전체를 한 번에 읽으므로** 여기서는 쓰지 않는다.

`yield`에서 멈춰 있는 동안에는 파일도 **열린 상태**다. 끝까지 읽으면 닫힌다.

빈 줄을 건너뛸 때는 `continue`(이번 차례는 넘어가기)를 쓴다.
```python
for line in ["가", "", "나"]:
    if line == "":
        continue
    print(line)       # 가, 나
```
