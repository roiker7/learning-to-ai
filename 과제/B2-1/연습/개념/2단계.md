# 2단계: argparse 3단계 패턴

1단계에서 직접 하던 일(꺼내기, 정수 변환, 오류 안내)을 대신해 주는 도구가 argparse이다.

```python
import argparse

parser = argparse.ArgumentParser(description="물건 가격")  # ① 만들기
parser.add_argument("item", help="물건 이름")               # ② 설정
parser.add_argument("price", type=int, help="가격")
args = parser.parse_args()                                  # ③ 해석

print(args.item, args.price + 100)
```

| 코드 | 리스트와 비교 |
|---|---|
| `parser = argparse.ArgumentParser()` | `names = []` (빈 것 만들기) |
| `parser.add_argument("item")` | `names.append("민수")` (추가하기) |
| `args = parser.parse_args()` | 실제로 해석하고 결과 받기 |

- `"item"`처럼 `--`가 없는 것은 **위치 인자**: 순서대로 넣고 꼭 써야 한다.
- `description=`처럼 `이름=값`으로 넘기는 것은 **키워드 인자**이다. `print("a", end="")`의 `end`와 같다.
- 결과는 `args.이름`으로 꺼낸다.
- `type=int`는 문자열을 정수로 바꾼다. 실패하면 argparse가 안내하고 종료 코드 2로 끝낸다.
- `--help`는 자동으로 생긴다.

손 연습: 위 코드를 `문제/price.py`에 직접 치고 정상 입력, `--help`, 값 누락, 가격에 글자 넣기를 실행해 본다.
