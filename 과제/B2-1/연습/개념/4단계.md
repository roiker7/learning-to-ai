# 4단계: 하위 명령과 분기

`git add`, `git commit`처럼 한 프로그램에 명령을 여러 개 두는 방법이다.

```python
import argparse

parser = argparse.ArgumentParser()
sub = parser.add_subparsers(dest="action")       # 명령 자리 만들기

feed = sub.add_parser("feed", help="밥 주기")    # 명령 등록
feed.add_argument("--food", default="사료")      # feed 전용 옵션

walk = sub.add_parser("walk", help="산책하기")
walk.add_argument("--minutes", type=int, default=10)

args = parser.parse_args()                       # 맨 위 parser로 한 번만

if args.action == "feed":
    print(args.food)
elif args.action == "walk":
    print(args.minutes)
```

```
parser (프로그램 전체)
└── sub (명령 자리, 고른 명령은 args.action)
    ├── feed ── --food
    └── walk ── --minutes
```
`feed`, `walk`도 각각 하나의 parser라서 2~3단계에서 배운 `add_argument`를 그대로 쓴다.
`walk`를 골랐을 때 `args.food`는 없다. 그래서 분기 안에서 그 명령의 값만 꺼낸다.

## 연습문제
### 4-1 (`문제/ex4_1.py`)
음악 플레이어. `--volume`은 정수이고 기본값은 5다.
```
$ python3 문제/ex4_1.py play 봄노래 --volume 8
재생: 봄노래 (볼륨 8)
$ python3 문제/ex4_1.py stop
정지
```
### 4-2 (`문제/ex4_2.py`)
계산기. `plus`는 정수 둘을 더하고, `repeat`은 글자를 `--times`번(기본값 2) 이어 붙인다.
```
$ python3 문제/ex4_2.py plus 3 5
8
$ python3 문제/ex4_2.py repeat 하 --times 3
하하하
```
