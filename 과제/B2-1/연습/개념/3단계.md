# 3단계: 옵션

`--`로 시작하면 **옵션**이다. 이름을 붙여 넣으므로 순서가 자유롭고, 기본적으로 생략할 수 있다.

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("city")
parser.add_argument("--days", type=int, default=1)
parser.add_argument("--grade", choices=["일반", "특실"], required=True)
parser.add_argument("--pet", action="store_true")
parser.add_argument("--class", dest="class_name")
args = parser.parse_args()

if args.pet:
    print(args.city, args.days, args.grade, "반려동물 동반")
```

| 설정 | 뜻 |
|---|---|
| `default=1` | 안 쓰면 1 |
| `choices=[...]` | 목록에 있는 값만 허용 |
| `required=True` | 옵션이지만 꼭 써야 함 |
| `action="store_true"` | 값 없이 쓰면 True, 안 쓰면 False |
| `dest="class_name"` | `args.class_name`에 담기 |

`default`가 없는 옵션을 생략하면 `None`이다.
`class`, `from`처럼 파이썬이 쓰는 단어(**예약어**)는 `args.class`라고 쓸 수 없다. 그래서 `dest`로 이름을 바꾼다.

## 연습문제
### 3-1 (`문제/ex3_1.py`)
`--count`는 정수이고 기본값은 1이다.
```
$ python3 문제/ex3_1.py 라떼 --count 2
라떼 2잔
$ python3 문제/ex3_1.py 라떼
라떼 1잔
```
### 3-2 (`문제/ex3_2.py`)
`--size`는 필수이며 S, M, L만 가능하다. `--ice`를 쓰면 차가운 음료다.
```
$ python3 문제/ex3_2.py 라떼 --size L --ice
차가운 라떼 L
$ python3 문제/ex3_2.py 라떼 --size S
따뜻한 라떼 S
```
### 3-3 (`문제/ex3_3.py`)
`--from`과 `--to`는 둘 다 필수다.
```
$ python3 문제/ex3_3.py --from 서울 --to 부산
서울 -> 부산
```
