# argparse 연습장

목표: 예시를 안 보고도 argparse 코드를 손으로 쓸 수 있게 되기

## 폴더 구성
- `개념/`: 단계별 설명 (먼저 읽기)
- `문제/`: 내가 코드를 작성하는 곳
- `채점.py`: 자동 채점 (수정하지 않기)
- `test.py`: 예전에 argparse를 연습하던 파일

## 사용법
```bash
cd 연습                             # 프로젝트 폴더에서 한 번만
python3 문제/ex1_1.py 민수 지우     # 직접 실행
python3 채점.py 1                   # 1단계 전체 채점
python3 채점.py 1_1                 # 1-1번만 채점
```

## 학습 순서 (단계마다 반복)
1. 개념 파일을 읽는다.
2. 예시를 복사하지 말고 **직접 친다**. 실행 전에 결과를 예상한다.
3. 문제를 푼다. 막히면 개념을 보고, 다시 닫고 쓴다.
4. 채점을 통과하면 코드를 지우고 **안 보고 한 번 더** 쓴다.
5. "말로 설명하기" 질문에 답한다.
