# 콘솔 가계부 애플리케이션 - 프로젝트 명세

## 1. 미션 소개

"작은 서비스"란 기능이 많은 게 아니라 예외 상황에서도 데이터가 안전한 것을 말합니다.

### 프로젝트 개요
Python으로 파일 입출력 기반의 콘솔 가계부 프로그램을 구현합니다. 
- 수입/지출을 단순히 저장하는 수준을 넘어서
- 수정/삭제, 검색, 월별 요약, 카테고리 관리, 예산 초과 경고를 포함한 "작은 서비스"로 완성

### 핵심 설계 원칙
1. **파일 기반 영구 저장**: JSONL 또는 CSV로 데이터 저장
2. **제너레이터 스트리밍**: `yield` 기반으로 대용량 파일 메모리 효율적 처리
3. **데코레이터 분리**: 로그/예외처리/시간 측정 등 공통 기능을 데코레이터로 분리
4. **타입 힌트 명시**: 함수와 데이터 구조의 계약을 명확하게
5. **모듈 분리**: 책임을 나누어 유지보수 가능한 구조 설계

## 2. 최종 결과물: 10가지 필수 기능

### 2.1 거래 추가 (add)
- **입력**: 대화형 입력 (날짜, 타입, 카테고리, 금액, 메모/태그)
- **출력**: 저장 성공 메시지 + 생성된 거래 ID

### 2.2 거래 목록 (list)
- **입력**: `--limit` 등 옵션
- **출력**: 최신순 거래 리스트 (스트리밍 처리)

### 2.3 거래 검색 (search)
- **입력**: `--from/--to`, `--category`, `--type`, `-q`, `--tag`
- **출력**: 조건에 맞는 거래 리스트 (최신순)

### 2.4 월별 요약 (summary)
- **입력**: `--month YYYY-MM`, `--top N`
- **출력**: 총수입/총지출/잔액 + 카테고리별 지출 TOP N

### 2.5 예산 설정/조회 (budget)
- **입력**: `budget set --month YYYY-MM --amount 금액`
- **출력**: 저장 성공 메시지 + summary에서 예산 사용률/초과 경고

### 2.6 카테고리 관리 (category)
- **입력**: `category add/list/remove`
- **출력**: 카테고리 목록/추가/삭제 결과 (사용 중 카테고리 처리)

### 2.7 거래 수정 (update)
- **입력**: `-id` 기반 (옵션 방식 또는 대화형 중 1가지 선택)
- **출력**: 수정 성공/실패 메시지 (없는 id 처리)

### 2.8 거래 삭제 (delete)
- **입력**: `delete --id <id>`
- **출력**: 삭제 성공/실패 메시지 (없는 id 처리)

### 2.9 가져오기/내보내기 (import/export)
- **입력**: `import --from <csv>`, `export --out <csv> --month ...` 또는 `--from/--to`
- **출력**: 처리 건수 출력 + CSV 파일 생성/반영 확인

### 2.10 추가 조건 (필수 구성)
- **데이터는 3개 이상 파일로 영구 저장**: transactions, categories, budgets
- **README.md 필수 포함**: 실행 방법, 저장 파일 위치/형식, 주요 명령 예시, import/export CSV 스키마

## 4. 기능 요구사항 상세

### 4.1 실행 및 입력 방식

**실행 방식**:
```bash
python -m budget_app <command> [options]
```

**필수 규칙**:
- 모든 명령은 `--help` 옵션으로 사용 방법 출력
- **기본 입력 방식**: 대화형 (e.g., add 시 날짜/타입/카테고리/금액 순차 입력)
- **옵션 방식도 허용** (권장): search, list, summary, export, import, delete
- **update**: 옵션 방식 또는 대화형 중 하나 선택 → 문서에 고정
- **옵션 표기**: 리눅스 표준 `--` 통일 (예: `--help`, `--limit`, `--from`, `--to`)

### 4.2 데이터 모델

**Transaction 필드**:
- `id` (유일) | `type` (income/expense) | `date` (YYYY-MM-DD) | `amount` (양수)
- `category` (필수) | `memo` (선택) | `tags` (선택)

**모델 구조 요구**:
- `dataclass` 또는 그에 준하는 구조
- 최소 2개 이상 클래스 사용
- 예: Transaction, TransactionRepository, BudgetStore, CategoryStore, BudgetService

### 4.3 입력 검증
- 날짜 형식 오류
- 음수/0 금액
- 허용되지 않은 type (income/expense 외)
- 존재하지 않는 category

처리: 재입력 요구 또는 명확한 오류 메시지

### 4.4 저장 정책

**저장 포맷**: JSONL 또는 CSV 중 1개 선택

**저장 파일 (필수 3개 이상)**:
```
data/
├── transactions.<fmt>
├── categories.<fmt>
└── budgets.<fmt>
```

**저장 폴더**: 기본 `./data`, 옵션으로 변경 가능 (`--data-dir`)

### 4.5 초기 실행 (저장 파일 없을 때)
- 파일이 없으면 자동 생성 또는 초기화 안내
- 카테고리 파일 비어있으면 (선택):
  - (안 A) 기본 카테고리 자동 생성 (food, transport, rent, etc)
  - (안 B) category add를 먼저 하도록 안내하고 add 차단

### 4.6 각 명령의 상세 요구

#### add (거래 추가)
- 대화형으로 필드 입력받아 저장
- category는 등록된 목록에 존재해야 함 (없으면 안내)
- 저장 완료 시 생성된 ID 출력

#### list (목록 조회)
- **최신순** 출력
- `--limit N` 옵션 지원 (기본값 제공)
- **제너레이터 기반 스트리밍 처리** (전체 파일 한 번에 로드 금지)

#### update/delete (수정/삭제)
- `delete --id <id>`로 삭제
- 없는 id는 "없는 데이터" 메시지
- **update 방식 선택** → 문서에 고정:
  - (안 A) 옵션 기반: `update --id <id> [--date ...] [--type ...] [...]`
  - (안 B) 대화형 기반: 수정할 필드만 선택/재입력
- 파일 update/delete는 **안정성 고려** (전체 재작성/임시 파일/원자적 교체)

#### search (검색)
- 조건 기반: `--from`, `--to`, `--category`, `--type`, `-q`, `--tag`
- **최신순** 결과
- **스트리밍 처리** (제너레이터) 유지

#### summary (월별 요약)
- 입력: `summary --month YYYY-MM`
- 출력:
  - 총 수입, 총 지출, 잔액
  - 카테고리별 지출 합계 TOP N (`--top` 옵션)
- 데이터 없으면 "데이터 없음" 명확히 출력

#### budget (예산)
- 저장: `budget set --month YYYY-MM --amount <금액>`
- `summary` 실행 시:
  - 예산 대비 사용률(%)
  - 초과 여부 (초과 시 경고)
- 예산 데이터도 **반드시 영구 저장**

#### category (카테고리 관리)
- `category add/list/remove` 제공
- 삭제 시 사용 중인 카테고리 처리:
  - 삭제 차단 또는
  - 대체 카테고리 요구

#### import/export (가져오기/내보내기)
- `import --from <csv>` → 거래 일괄 등록
- `export --out <csv> --month ...` 또는 `--from/--to` → CSV 저장
- **export 필수 조건**: `--month YYYY-MM` 또는 `--from YYYY-MM-DD --to YYYY-MM-DD` 중 하나 이상
- **CSV 최소 스키마**:
  ```
  date,type,category,amount,memo,tags
  2024-01-15,income,salary,3000000,January salary,
  ```
