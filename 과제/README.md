## 합치는 원칙
- 커밋 기록까지 가져온다(`git subtree`). 로컬이 아니라 최신 원격을 기준으로 하고, 커밋하지 않은 변경은 학습자에게 확인한다.
- 이 저장소는 공개이므로 **합치기 전에 커밋 기록의 비밀번호, API 키, 개인 정보를 점검**한다.
- 원본 저장소는 지우거나 바꾸지 않는다(이미 제출한 링크와 배포 유지).
- 다른 사람의 저장소인 팀 작업(`cody_git_team`)은 합치지 않고 필요하면 링크만 남긴다.
- 동작은 바꾸지 않는다.
