## 다른 컴퓨터에서 이어서 하기
1. 처음 한 번 저장소를 받는다.
   ```bash
   git clone https://github.com/roiker7/learning-to-ai.git
   ```
   이미 받은 컴퓨터에서는 저장소 폴더에서 `git pull`을 실행한다.
2. VSCode로 `learning-to-ai` 폴더를 열고 Claude Code에서 새 대화를 시작한다.
3. **"학습 시작"** 이라고 말한다. Claude가 기록을 읽고 이어서 진행한다.
4. 끝낼 때 **"오늘 마무리"** 라고 말한다. Claude가 기록하고 커밋·푸시한다.

푸시하려면 그 컴퓨터에서 GitHub에 로그인되어 있어야 한다. 마무리하지 않은 내용은 다른 컴퓨터에서 볼 수 없다.
