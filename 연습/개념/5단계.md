# 5단계: 명령 누락 처리와 2단 명령

## 1. 명령이 없을 때
명령을 안 쓰면 `args.action`은 `None`이다. 아무 말 없이 끝내지 말고 사용법을 알려준다.
- `parser.print_help()`: 도움말 출력
- `sys.exit(숫자)`: 종료 코드를 정해 끝내기. 0은 정상, 나머지는 오류
- 직전 종료 코드는 터미널에서 `echo $?`로 확인

## 2. 함수로 나누기
명령이 늘면 분기 안이 길어진다. 명령마다 함수를 만들고 `args`를 넘긴다.
```python
def do_feed(args):
    print(args.food)
```

## 3. 2단 명령
`zoo animal add 사자`처럼 명령 안에 명령을 둘 수 있다. `animal`도 parser라서 4단계를 한 번 더 하면 된다.
```python
animal = sub.add_parser("animal")
animal_sub = animal.add_subparsers(dest="animal_action")  # dest 이름은 다르게
animal_add = animal_sub.add_parser("add")
```

## 연습문제
### 5-1 (`문제/ex5_1.py`)
`on`과 `off` 명령이 있는 전등. 명령이 없으면 도움말을 보여주고 0이 아닌 코드로 끝낸다.
```
$ python3 문제/ex5_1.py on
전등 켜짐
$ python3 문제/ex5_1.py off
전등 꺼짐
```
### 5-2 (`문제/ex5_2.py`)
도서관. `book add`, `book remove`, `search` 명령을 명령별 함수로 나눈다.
`search`의 `--limit`은 정수이고 기본값은 10이다. `book`만 쳤을 때도 도움말을 보여주고 0이 아닌 코드로 끝낸다.
```
$ python3 문제/ex5_2.py book add 어린왕자
추가: 어린왕자
$ python3 문제/ex5_2.py book remove 어린왕자
삭제: 어린왕자
$ python3 문제/ex5_2.py search 왕자 --limit 3
검색: 왕자 (최대 3건)
```
