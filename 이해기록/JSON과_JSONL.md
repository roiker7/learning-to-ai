# JSON과 JSONL
- 등급: A(JSONL/CSV 처리)의 선행 개념 / 과제: B2-1 / 상태: **통과** (파일 읽기·쓰기는 JSONL/CSV에서 따로 배움) / 날짜: 2026-11-25

## 내 설명
- "jsonl은 한 줄씩 데이터를 저장하는 걸로 알고 있어" (설명을 듣기 전)
- 메뉴 JSON 배열을 JSONL로 정확히 바꿈
- 2번째 줄의 `}`가 빠진 JSONL: "1,3번줄은 성공 / 2번은 실패(괄호가 닫히지 않아서)"

## 틀렸거나 빠졌던 점
- 설명 전에는 첫 1건만 볼 때의 차이와 `[`가 오류인 이유를 몰랐음
- 큰 파일에서 JSONL이 메모리에 유리한 이유는 아직 직접 설명하지 않음 → 제너레이터와 JSONL/CSV에서 확인

## 바로잡은 이해 (Claude의 설명)
- JSON 배열은 파일 전체가 값 하나, JSONL은 한 줄마다 완결된 값 하나
- 그래서 JSONL은 첫 줄만 읽고 멈출 수 있고, 한 줄이 깨져도 다른 줄은 해석할 수 있음

## AI 개발에서 쓰이는 곳 (Claude의 설명)
- 큰 학습 데이터를 한 줄씩 저장하고 읽을 때
