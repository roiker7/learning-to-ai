## 틀렸거나 빠졌던 점
- 종합 1차(2026-11-27): "왜 어떻게 하는지 잘 모르겠어". 읽기를 `yield`로 써서 함수가 제너레이터가 됨(건수 대신 generator 반환), `json.dumps(line)`(loads와 반대), 읽기 with와 쓰기 with를 따로 둠, 쓰기 파일에 "w" 없음, `for row in fields`로 헤더를 여러 번 씀, 레코드에서 fields 순서로 값을 꺼내는 부분 없음 → 전체 흐름(읽은 즉시 한 줄 쓰기)과 단계를 설명, 값 꺼내기는 다른 소재 예시로 설명
- 종합 2차: `yield`를 `return json.loads(line)`으로 바꿔 첫 레코드에서 함수가 끝남. 여전히 읽기 with와 쓰기 with를 따로 두고 fields를 한 칸씩 writerow → **"읽는 단계에서 넘겨주고 쓰는 단계에서 받는다"는 식으로 두 단계를 분리해 생각하는 듯**. 두 번 막혀 선행 개념(return은 함수를 즉시 끝냄, 읽기 for 안에서 바로 쓰기)과 들여쓰기 뼈대를 보여 줌
- 종합 3차(작성 중): 두 파일을 한 with로 열고 헤더 쓰기·빈 줄 건너뛰기까지 작성. `csv.writer(csv_path)`(경로를 넣음 → `argument 1 must have a "write" method`), `json.loads(line)` 결과를 변수에 담지 않음, 값 꺼내기 이후 미작성
  - writer(file_c), `a = json.loads(line)`, `cnt`, `return cnt`까지 고침(건수 통과). **fields 순서로 값을 꺼내 리스트에 담는 부분에서 "모르겠어"** → 변수에 든 키로 딕셔너리 값 꺼내기(`a[key]`)를 출력으로 단계별 설명
  - 단계별 설명 뒤에도 "잘 모르겠어". 정의되지 않은 `row`로 `writer.writerow(row)`만 씀 → 빈 리스트에 `append`로 모으는 것(선행 개념)이 익숙하지 않은 듯. append부터 설명하고 다른 소재의 작은 문제를 냄
  - 작은 문제(prices/items로 result 모으기 3줄)도 "모르겠어" → 그 문제의 답을 한 줄씩 풀어 보여 줌. 긴 학습 뒤라 피로도 의심. **다음에 다시 확인할 것: 빈 리스트 + for + append로 모으기, 변수에 든 키로 딕셔너리 값 꺼내기**
  - 학습자: 지쳐서인 것 같다고 동의, 그래도 종합까지 끝내고 싶다고 함 → 이름 바꿔 끼우기 표로 안내. `values.append(key)`(열 이름을 담음) → `a[key]`로 고쳐 **종합 채점 통과(2026-11-27)**
- 3-1 1차(2026-11-27): 쓰기 모드 파일에 `for line in file`(읽기 습관) → `UnsupportedOperation: not readable`. writer를 반복 안에서 만들고 `writerow([])`로 빈 줄만 씀. header·rows 인자를 쓰지 않음 → "읽을 때는 파일을 돌고, 쓸 때는 데이터(rows)를 돈다"로 설명

- 3단계 말로 설명: "newline은 줄바꿈 두 번 방지, utf-8-sig는 엑셀 한글 깨짐 방지"(맞음) / 줄바꿈·쉼표·목록 값에 편한 것 → "csv가 자동으로 해줘서 더 편할 거 같은데"(쉼표·줄바꿈은 csv도 따옴표로 처리하므로 일부 맞음. 목록과 숫자는 CSV가 글자로만 저장해 `"['가족', '스릴러']"` 같은 글자가 됨, JSONL은 리스트·숫자를 그대로 저장 → 설명 후 다른 문제)
