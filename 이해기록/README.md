# 이해기록

배운 개념을 **내가 어떻게 이해했는지** 검증한 뒤 파일 하나씩 기록한다. 배울 때 읽는 설명과 예시는 `과제/<과제>/코드연습/<개념>/개념/`에 있다.

| 개념 | 상태 |
|---|---|
| [JSON과 JSONL](JSON과_JSONL.md) | 통과 (선행 개념) |
| [제너레이터](제너레이터.md) | 통과 (2026-11-27) |
| [JSONL/CSV 처리](JSONL_CSV.md) | 통과 (2026-11-27) |

(argparse 연습 내용은 [진도](../진도.md)의 복습 목록 참고)

## 기록 형식
```markdown
# 개념 이름
- 등급 / 과제 / 상태(통과 또는 미통과) / 날짜

## 내 설명
(학습자가 대화에서 한 설명을 살려서)

## 틀렸거나 빠졌던 점
## 바로잡은 이해
## AI 개발에서 쓰이는 곳
## 참고한 자료 (실제로 본 것만)
## 다시 풀어 볼 질문
```
